
Resolve inline specs as native JSON

$ conda presto -c conda-forge -p linux-64 zlib > specs.json

$ jq '[.[] | {platform, packages: [.packages[].name], error}]' specs.json
[
  {
    "platform": "linux-64",
    "packages": [
      "libzlib",
      "zlib"
    ],
    "error": null
  }
]

Resolve an environment file for Linux and macOS

$ cat environment.yml
name: presto-demo
channels:
  - conda-forge
dependencies:
  - zlib>=1.3,<2
  - zstd>=1.5,<2

$ conda presto -f environment.yml -p linux-64 -p osx-arm64 > environment.json

$ jq -c '.[] | {platform, packages: (.packages | length), error}' environment.json
{"platform":"linux-64","packages":3,"error":null}
{"platform":"osx-arm64","packages":3,"error":null}

Merge two environment files and an inline requirement

$ cat extra-deps.yml
channels:
  - conda-forge
dependencies:
  - xz>=5,<6

$ conda presto -f environment.yml -f extra-deps.yml -p linux-64 bzip2 > merged.json

$ jq -r '[.[0].packages[].name] | sort | join(", ")' merged.json
_openmp_mutex, bzip2, libgcc, libgomp, liblzma, liblzma-devel, libzlib, xz, xz-gpl-tools, xz-tools, zlib, zstd

Export exact package URLs for conda create --file

$ conda presto -f environment.yml -p linux-64 --format explicit > explicit.txt

$ sed -n '/^@EXPLICIT/,$p' explicit.txt
@EXPLICIT
https://conda.anaconda.org/conda-forge/linux-64/libzlib-1.3.2-h25fd6f3_3.conda
https://conda.anaconda.org/conda-forge/linux-64/zlib-1.3.2-h25fd6f3_3.conda
https://conda.anaconda.org/conda-forge/linux-64/zstd-1.5.7-hb78ec9c_7.conda

Install later with: conda create -n demo --file explicit.txt

Normalize declarations without solving

$ conda presto --export -f environment.yml --format requirements > requirements.txt

$ cat requirements.txt
# This file may be used to create an environment using:
