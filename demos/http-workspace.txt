
Discover workspace environments without solving

$ jq -n --rawfile file conda.toml '{file:$file,filename:"conda.toml"}' > workspace.json

$ curl --fail --silent --show-error http://127.0.0.1:51948/parse --json @workspace.json > discovery.json

$ jq -c '.environments[] | {name, platforms}' discovery.json
{"name":"default","platforms":{"cpu":"linux-64","gpu":"linux-64"}}
{"name":"tools","platforms":{"cpu":"linux-64","gpu":"linux-64"}}

$ jq .selected discovery.json
[]

Select tools/gpu with its declared system requirements

$ jq '. + {environments:["tools"],platforms:["gpu"]}' workspace.json > selected.json

$ curl --fail --silent --show-error http://127.0.0.1:51948/parse --json @selected.json > selected-result.json

$ jq '.selected[0] | {environment, platform, subdir, specs, system_requirements}' selected-result.json
{
  "environment": "tools",
  "platform": "gpu",
  "subdir": "linux-64",
  "specs": [
    "zlib[version='>=1.3,<2']",
    "zstd[version='>=1.5,<2']"
  ],
  "system_requirements": {
    "glibc": "2.28",
    "cuda": "12"
  }
}

Export the selected requirements without solving

$ curl --fail --silent --show-error 'http://127.0.0.1:51948/export?format=requirements' --json @selected.json > requirements.txt

$ cat requirements.txt
# This file may be used to create an environment using:
# $ conda create --name <env> --file <this file>
# platform: linux-64
# created-by: conda 26.5.3
# Note: This is a conda requirements file (MatchSpec format)
# Contains conda package specifications, not pip requirements

zlib[version='>=1.3,<2']
zstd[version='>=1.5,<2']
Solve the complete workspace into one lock

$ curl --fail --silent --show-error 'http://127.0.0.1:51948/resolve?format=conda-workspaces-lock-v1' --json @workspace.json > conda.lock

$ jq -n --rawfile file conda.lock '{file:$file,filename:"conda.lock"}' > lock.json

$ curl --fail --silent --show-error http://127.0.0.1:51948/parse --json @lock.json > saved.json

$ jq -c '.environments[] | {name, platforms}' saved.json
{"name":"default","platforms":{"cpu":"linux-64","gpu":"linux-64"}}
{"name":"tools","platforms":{"cpu":"linux-64","gpu":"linux-64"}}

The lock contains both environments and both named targets
