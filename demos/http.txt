
Discover the installed Pixi output formats

$ curl --fail --silent --show-error http://127.0.0.1:51518/formats > formats.json

$ jq '.formats | map(select(startswith("pixi")))' formats.json
[
  "pixi",
  "pixi-lock-v6",
  "pixi-toml"
]

Solve zlib for Linux and inspect the result

$ curl --fail --silent --show-error -H 'Content-Type: application/json' --data '{"specs":["zlib"],"channels":["conda-forge"],"platforms":["linux-64"]}' http://127.0.0.1:51518/resolve > result.json

$ jq '[.[] | {platform, error, packages: [.packages[].name]}]' result.json
[
  {
    "platform": "linux-64",
    "error": null,
    "packages": [
      "libzlib",
      "zlib"
    ]
  }
]

Upload an environment file and save a Pixi lock

$ cat environment.yml
name: presto-demo
channels:
  - conda-forge
dependencies:
  - zlib>=1.3,<2
  - zstd>=1.5,<2

$ curl --fail --silent --show-error --dump-header headers.txt -H 'Content-Type: application/yaml' --data-binary @environment.yml 'http://127.0.0.1:51518/resolve?filename=environment.yml&platform=linux-64&format=pixi-lock-v6' > pixi.lock

$ head -n 8 pixi.lock
version: 6
environments:
  default:
    channels: []
    packages:
      linux-64:
        - conda:
            https://conda.anaconda.org/conda-forge/linux-64/libzlib-1.3.2-h25fd6f3_3.conda

Retrieve the exact output from its retained location

$ grep -i '^location:' headers.txt
location: /r/a653000c1d33d3fdef148c701c2f38e9ff9eff183a9cae2c3b0373d4bf7a0ca2

$ curl --fail --silent --show-error http://127.0.0.1:51518/r/a653000c1d33d3fdef148c701c2f38e9ff9eff183a9cae2c3b0373d4bf7a0ca2 > retained.lock

$ cmp pixi.lock retained.lock

The retrieved lock is byte-for-byte identical
