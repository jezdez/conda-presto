
Validate the complete saved lock against its manifest

$ jq -n --rawfile file conda.lock --rawfile manifest conda.toml '{file:$file,filename:"conda.lock",manifest:$manifest,manifest_filename:"conda.toml"}' > baseline.json

$ curl --fail --silent --show-error http://127.0.0.1:51523/validate --json @baseline.json > consistency.json

$ jq '{consistent, targets:(.targets | length)}' consistency.json
{
  "consistent": true,
  "targets": 4
}

A changed manifest returns a mismatch with HTTP 200

$ jq '.manifest |= sub(">=1.3,<2"; ">=99")' baseline.json > changed.json

$ curl --fail --silent --show-error http://127.0.0.1:51523/validate --json @changed.json --write-out 'HTTP %{http_code}\n' --output mismatch.json > mismatch-status.txt

$ cat mismatch-status.txt
HTTP 200

$ jq '{consistent, reason:.targets[0].reason}' mismatch.json
{
  "consistent": false,
  "reason": "Dependency 'zlib' in environment 'default' requires 'zlib[version='>=99']' but locked package 'conda-forge/linux-64::zlib-1.3.2-h25fd6f3_3' on 'cpu' does not satisfy it"
}

Update tools/cpu using the original consistent baseline

$ jq '. + {environment:"tools",platform:"cpu",packages:["zstd"]}' baseline.json > update.json

$ curl --fail --silent --show-error http://127.0.0.1:51523/update --json @update.json > updated.lock

$ python check_update.py conda.lock updated.lock
Unchanged package references: default/cpu, default/gpu, tools/gpu

Validate all four targets in the returned lock

$ jq --rawfile file updated.lock '.file = $file' baseline.json > updated.json

$ curl --fail --silent --show-error http://127.0.0.1:51523/validate --json @updated.json > updated-check.json

$ jq '{consistent, targets:(.targets | length)}' updated-check.json
{
  "consistent": true,
  "targets": 4
}
