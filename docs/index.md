# conda-presto

conda-presto exposes conda solving, input parsing and output rendering through an HTTP service. Other systems can request fully resolved packages for explicit target platforms without installing conda or changing an environment themselves.

Start with the {doc}`quickstart`, then follow the {doc}`tutorials/http-api` or {doc}`tutorials/workspaces` tutorial. Watch the executable workflows in {doc}`demos/index`. The package also provides a one-shot CLI and a server launcher. The GitHub Action calls an explicitly configured service.
